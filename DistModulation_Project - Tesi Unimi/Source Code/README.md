# **SOURCE CODE**

## **---ITALIANO---**

In questa cartella sono presenti i file.cpp principali riguardo la programmazione separata dei 3 effetti che compongono il plugin, in più è presente il file PluginProcessor.cpp per mostrare come i 3 effetti vengono in uniti in un unica catena e il file PluginParameters.h per mostrare come vengono gestiti tutti i parametri del plugin.

AnalogDelay.cpp -> Effetto di Delay
Distortion.cpp -> Effetto di Distorsione
Chorus.cpp e ModulationChorus.cpp -> Effetto di Chorus

## **---ENGLISH---**
This folder contains the main .cpp files for the separate programming of the three effects that make up the plugin; additionally, it includes PluginProcessor.cpp, demonstrating how the three effects are combined into a single chain, and PluginParameters.h, showing how all plugin parameters are managed.

AnalogDelay.cpp -> Delay effect
Distortion.cpp -> Distortion effect
Chorus.cpp and ModulationChorus.cpp -> Chorus effect
